# 🌙 Sleep Road

> Мобильный 3D crowd runner от **Sleepkidd Studio** — собирай толпу, выбирай математические ворота, обходи ловушки и поднимайся по лестнице множителей.

## Что внутри

- до **999 участников** в игровой логике и до 420 одновременно отрисованных моделей;
- сбор лун всей площадью толпы: монету может подобрать любой участник, а не только центральная точка;
- рабочая финишная лестница `×1.35…×3.80` с прозрачным расчётом итоговой награды;
- ворота `+N`, `−N`, `×N`, `÷N`, включая обязательные рискованные красные варианты;
- 12 видов препятствий: вращающиеся лопасти, пилы, толкатели, столбы, шипы, барьеры, мины, молоты, бочки, лазеры, дробилки и маятники;
- столкновения по каждому участнику толпы, щиты, битвы, боссы и три типа миссий;
- постоянные улучшения толпы, магнита и дохода;
- управление свайпом, мышью, стрелками и `A/D`;
- адаптивный мобильный интерфейс, звук, сохранение и офлайн-режим PWA.



Sleep Road работает без игрового фреймворка: проект использует собственный компактный WebGL-рендерер с instanced rendering, перспективной камерой и fallback с WebGL 2 на WebGL 1.

| Файл | Назначение |
|---|---|
| `engine.js` | WebGL-рендерер, матрицы, камера и меши |
| `assets/models/countmaster-character.js` | адаптированный меш персонажа CountMaster |
| `assets/models/pickup-model.js` | полноразмерный меш пикапа из Blender: 13 110 треугольников, без Decimate/упрощения геометрии |
| `systems-v4.js` | сохранения, звук, формирование и отрисовка толпы |
| `gameplay-v4.js` | игровой цикл, генерация, столкновения и экономика |
| `render-v4.js` | трасса, окружение, ворота, препятствия и финиш |
| `boot-v4.js` | запуск игры и service worker |
| `sw.js` | офлайн-кэш PWA |

## Локальный запуск

```bash
python -m http.server 8080
```

Открой `http://localhost:8080`. Нужен современный браузер с WebGL.

Проверка игровой логики без дополнительных зависимостей:

```bash
node tests/gameplay-smoke.test.js
```

## Проверка модели

```bash
python tools/convert_countmaster_fbx.py \
  "/path/to/CountMaster/Assets/3D Assets/CharacterFBX.fbx" \
  assets/models/countmaster-character.js
```

Скрипт снова создаст тот же браузерный меш и напечатает количество вершин и треугольников.
