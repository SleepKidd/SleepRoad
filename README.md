# Sleep Road

**Sleep Road** — оригинальная браузерная 3D crowd-runner игра от **Sleepkidd Studio**.

Проект использует собственный мини-3D движок на WebGL с WebGL 2 и WebGL 1 fallback: без Unity, без Three.js и без копирования исходного кода или ассетов других игр. Игровая формула относится к жанру crowd runner: игрок ведёт толпу, выбирает математические ворота, собирает валюту, проходит ловушки, сражается с другими толпами и получает финишный множитель.

## Что реализовано

- настоящий перспективный 3D-рендер на WebGL 2 с WebGL 1 fallback;
- детализированные низкополигональные персонажи из 18 частей: округлое тело, правильные плечи и рукава, аккуратные пропорции рук и ног, разные оттенки кожи, одежда, причёски, лицо, обувь, тени и плавная анимация бега;
- плотная синяя толпа игрока и красные вражеские толпы;
- размер толпы до 999 человек; до 420 персонажей одновременно отображаются отдельными моделями;
- сбалансированные ворота `+N`, `−N`, `×N`, `÷N`: красные отрицательные варианты встречаются регулярно, включая пары без положительного выбора;
- сбор лун и магнитный радиус;
- двенадцать типов препятствий: вращающиеся лопасти, пилы, толкатели, столбы, разбросанные шипы, дорожные барьеры, мины, маятниковые молоты, катящиеся бочки, лазерные коридоры, движущиеся дробилки и подвесные шары;
- препятствия рассчитывают столкновение каждого участника с учётом его ряда и движения механизма, после чего выбивают попавших персонажей;
- защитные сферы-щиты, полностью гасящие одно столкновение;
- три чередующихся типа миссий уровня — сбор лун, идеальные манёвры и доставка толпы — с дополнительными наградами;
- автоматические битвы толпа-против-толпы;
- финишная лестница с множителем;
- магазин постоянных улучшений: стартовая толпа, магнит, доход лун;
- сохранение через `localStorage`;
- управление свайпом, мышью, `A/D` и стрелками;
- адаптивный мобильный HUD;
- кнопка выхода в меню во время забега и на экране результата, а также клавиша `Esc` на компьютере;
- удлинённые уровни с увеличенным расстоянием между испытаниями;
- усиленная динамическая камера и масштаб моделей для толпы в 300–420 видимых персонажей без перекрытия трассы;
- обновлённая дорога, корректное направление движения разметки и леса, процедурная расстановка деревьев, горы, солнце, облака, дорожные отражатели, цветовая схема и эффекты попаданий;
- PWA/service worker;
- GitHub Pages из `main` → `/(root)`.

## Структура

- `engine.js` — собственный WebGL renderer, матрицы, камеры, меши и instanced rendering;
- `systems-v4.js` — сохранения, звук, crowd batching и общие игровые системы;
- `gameplay-v4.js` — игровой цикл, генерация уровня, столкновения, экономика и магазин;
- `render-v4.js` — 3D-сцена, препятствия, толпы, ворота и финиш;
- `boot-v4.js` — запуск приложения и service worker;
- `index.html` — HUD, меню, магазин и результаты;
- `style.css` — мобильный интерфейс;
- `sw.js` — offline cache;
- `manifest.webmanifest` — PWA.

## Локальный запуск

```bash
python -m http.server 8080
```

После этого открой `http://localhost:8080`.

> Нужен браузер с WebGL. Движок предпочитает WebGL 2 и автоматически использует WebGL 1 fallback, когда WebGL 2 недоступен.
