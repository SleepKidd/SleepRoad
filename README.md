# Sleep Road

**Sleep Road** — браузерная crowd-runner игра от **Sleepkidd Studio**. Игрок ведёт толпу по ночной дороге, выбирает математические ворота, собирает луны, избегает препятствий, сражается с вражескими толпами и прокачивает стартовые характеристики.

## Что есть в игре

- хорошо читаемая толпа с крупными персонажами и динамической формацией;
- ворота `+N`, `−N`, `×N` и редкие рискованные варианты;
- коллекционные луны с магнитом;
- магазин постоянных улучшений: стартовая толпа, магнит и лунный бонус;
- простые, понятные препятствия: вращающиеся лопасти, лунные пилы, шипы, толкатели и дорожные блоки;
- вражеские толпы и усиленные противники;
- финишная лестница с множителем награды;
- процедурная генерация уровней с постепенным ростом сложности;
- управление свайпом, мышью, `A/D` и стрелками;
- сохранение прогресса через `localStorage`;
- адаптивный интерфейс для телефонов и ПК;
- PWA и офлайн-кэш.

## Структура

- `index.html` — UI, HUD, магазин и экраны результата;
- `style.css` — адаптивный интерфейс;
- `game.js` — игровой цикл, генерация уровней, столкновения, магазин и Canvas-рендер;
- `manifest.webmanifest` — PWA-манифест;
- `sw.js` — service worker;
- `icon.svg` — иконка игры;
- `.nojekyll` — публикация GitHub Pages без Jekyll.

## Запуск локально

```bash
python -m http.server 8080
```

Открой `http://localhost:8080`.
