# Sleep Road

**Sleep Road** — браузерная crowd-runner игра от **Sleepkidd Studio**. Игрок ведёт толпу по дороге сна, выбирает математические ворота, собирает луны, проходит простые читаемые ловушки, сражается с вражескими толпами и прокачивает постоянные улучшения.

## Что реализовано

- крупная хорошо видимая толпа с псевдо-3D персонажами, тенями и анимацией бега;
- синхронизированная позиция толпы и препятствий — столкновения происходят именно в момент визуального контакта;
- потери рассчитываются по расположению отдельных участников толпы, а не только по центру игрока;
- при ударе участники визуально вылетают из толпы, есть частицы, shake и счётчик потерь;
- ворота `+N`, `−N`, `×N`, `÷N` с разными вариантами выбора;
- коллекционные **луны** на трассе и улучшение радиуса магнита;
- магазин постоянных улучшений: стартовая толпа, магнит, лунный доход;
- простые препятствия в духе crowd-runner: вращающиеся лопасти, пилы на рельсах, шипы, боковые толкатели и красные дорожные столбы;
- препятствия сделаны читаемыми и не перегружают трассу;
- вражеские толпы и периодические усиленные противники;
- финишная лестница с множителем награды;
- мягкая светлая дорога с низкоконтрастными секциями вместо агрессивной «зебры»;
- процедурная генерация уровней с постепенным ростом сложности;
- управление свайпом, мышью, `A/D` и стрелками;
- сохранение прогресса через `localStorage`;
- адаптация под телефоны и ПК;
- PWA и offline cache через Service Worker.

## Структура

- `index.html` — интерфейс, HUD, магазин и экраны результата;
- `style.css` — базовое адаптивное оформление;
- `refinement.css` — финальная визуальная настройка HUD и меню;
- `game.js` — базовый игровой цикл;
- `gameplay-v3.js` — актуальная механика толпы, ворот и столкновений;
- `render-v3.js` — актуальный Canvas-рендер дороги, персонажей и препятствий;
- `manifest.webmanifest` — PWA-манифест;
- `sw.js` — service worker и offline cache;
- `icon.svg` — иконка;
- `.nojekyll` — корректная публикация GitHub Pages из корня.

## Локальный запуск

```bash
python -m http.server 8080
```

После этого открой `http://localhost:8080`.
