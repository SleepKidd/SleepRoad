# Sleep Road

**Играть:** https://sleepkidd.github.io/SleepRoad/

Атмосферная браузерная crowd-runner игра, вдохновлённая механикой «собери толпу → выбери математические ворота → переживи препятствия и битвы → дойди до финиша».

## Что уже есть

- адаптивное управление свайпом, мышью, `A/D` и стрелками;
- математические ворота `+N` и `×N`;
- вражеские толпы и автоматические столкновения;
- препятствия разных типов;
- бонусы, луны, серия-комбо и щит;
- процедурная генерация уровней;
- анимированная 2.5D-графика на Canvas без внешних библиотек;
- эффекты частиц, свечение, облака, звёзды и динамический фон;
- процедурные звуки через Web Audio API;
- сохранение прогресса и рекордов в `localStorage`;
- PWA-манифест и service worker для установки/офлайн-кэша.

## Запуск

Никакой сборки не требуется. Для корректной работы service worker запускай через HTTP-сервер, например:

```bash
python -m http.server 8080
```

После этого открой `http://localhost:8080`.

## Структура

- `index.html` — интерфейс и HUD;
- `style.css` — адаптивный UI;
- `game.js` — игровой цикл, рендер, физика и генерация уровней;
- `manifest.webmanifest` — PWA;
- `sw.js` — офлайн-кэш;
- `icon.svg` — иконка.
